# Deno snippets

Most of these are not meant to be used in serious apps, 
they are snippets to get my toys to production, 
and share them with friends and family as soon as possible.

- [naive-deploy.sh](naive-deploy.sh) can be used along with github actions for deploy on merge or something like that
- [web-facade.ts](web-facade.ts) framework-less web facade (REST, SSE, etc)
- [local-storage-repo.ts](local-storage-repo.ts) naive local storage repository
